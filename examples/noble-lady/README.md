# 贵族角色公开案例

本目录展示六个主阶段与两次修正，共 8 张真实 PNG。图像字节与原输出一致，SHA-256 见 [manifest.json](manifest.json)。通过 [index.html](index.html) 切换比较、查看局部并浏览失败候选。

[preview.jpg](preview.jpg) 是该页面在 Edge 中实际运行时的截图，不是概念效果图。

这是公开展示副本，不是可继续运行的完整 CLI 项目。原始对话、用户指令、完整提示词、人工证据、调用事件和来源机器路径未公开。页面说明为公开展示重新编写，不是用户原话。

所有阶段选择来自代理试跑。图片获准在本项目公开展示，但尚未人工审美定稿；没有人工修绘或分层源文件。具体后台模型未获返回，标为 UNKNOWN_BUILTIN。

两张未选用图分别出现分色偏差与不需要的衣料碎褶；它们保留用于解释修正过程，不应误认为丢弃文件或最终结果。最终候选并不因此在所有维度优于直接成图。

本案例记录的外部艺术图输入数量为零；本目录不含第三方参考图库。维护者批准的是本项目中的公开展示，尚未指定向公众提供的通用再使用许可证。
