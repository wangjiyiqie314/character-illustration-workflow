# 绘画检查规则

用头部朝向轴、可见耳朵与鼻尖、颈柱、胸腔和骨盆体块、四肢体积及脚底解释动作。火柴人关节点不能单独证明深度、头颈扭转或手部自然。AI体块参考也可能错，检查合格之后才固定。

逐张对照上一阶段和固定参考：头与胸腔能否同时成立、颈部从哪里连接、肩膀接哪条手臂、膝与脚尖是否兼容、两脚是否在同一地面、重心是否有支撑。眼神改变不等于整颗头转向。二维读图判断不是精确关节角度测量。

细化脸部眼睑、眉眼关系、眼球方向、鼻口与下颌；头发发根、主束、层叠与发梢；衣物版型、接缝、厚度、受力与重力褶皱；装备包盖开口、侧厚、扣环和肩带路径、鞋面与鞋底；手部五指、指节、遮挡和持物接触。不要用更多散丝、随机褶皱、挂饰或晶体碎片代替构造。

另做褶皱检查：每条主要褶能否追溯到肩、腰、肘、悬挂点或重力？接缝、拼片和装饰边是否被误认成皱纹？挺括胸腹大面应连续，厚裙主褶宽而有疏密，不在所有区域均匀填线。线稿不沿每个高光/阴影边界描线，光影不重新制造线稿里没有的碎皱。衣物不必绝对无褶；重点是形体解释与材质一致。

场景检查构件厚度、透视、脚底与台阶关系、轮廓间隙和线条层级。背景可以丰富，焦点周围不能被杂线穿过。若结构稿已经较细，诚实记录下一步细化增益有限，避免假称每轮大幅提升。

平涂锁定颜色，不重设计造型；工具若添加阴影或纹理，记录偏差，不称严格无阴影底色。光影检查共同主光、接触阴影与投影，水晶局部光须作为明确次光源。材质区分靠受光与构造，不靠统一塑料亮面或均匀颗粒。

精修只针对实际读图发现；没有明显改善就记录增益有限。检查不能取代用户审美认可，也不能证明工作流普遍降低AI感。需要严格线稿保留时，人工在独立线稿、颜色和阴影层完成；只有实际制作验证的文件才叫分层源文件。
