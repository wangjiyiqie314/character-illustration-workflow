# 材质与褶皱控制

先确认版型、材料厚度、支撑点与主要受力，再决定褶皱。细节的作用是解释结构；更多细线或纹理不自动增加完成度。

线稿阶段区分接缝、分色边和真正的折叠。平整衣片保留连续大面，关节附近使用少量必要压缩褶，厚重悬垂材料使用较宽的主褶。不要沿每个阴影边界重新描线。

平涂阶段建立区域色表，明确同一衣片的固有色；不把接缝自动当成换色边，不用光影掩盖分区错误。输出若仍有渐变，记录实际偏差，不宣称它是严格分层平涂。

光影阶段保持线稿与色表，使用一致的主光和合理接触阴影。通过高光范围、边缘和色阶区分皮肤、布料、皮革、金属等材质；避免所有表面拥有同样的反光。

如果完整成图作为参考时恢复了不需要的褶皱或旧渲染，先检查作用冲突，再决定是否仅使用当前合格线稿和平涂。撤下源图需要记录原因，并继续在生成后核对脸、姿态和服装构件。

最后比较实际变化：哪些结构更清楚，哪些笔触或体积信息丢失，哪些仍需要人工修绘。保持原图和失败候选，不用流程长度替代效果评价。
